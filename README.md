# Daily Food Products - Order Management App

A beautiful, fast, and easy-to-use order management system for Daily Food Products SDN BHD. Built with HTML/CSS/JavaScript - no backend required!

## ✨ Features

✅ **Complete Product Catalog** - All 120+ products with codes, sizes, and prices
✅ **Sales Agent Tracking** - Record which agent placed the order
✅ **Store Management** - Quick store selection with autocomplete
✅ **Smart Search** - Find products by name or code instantly
✅ **Professional Formatting** - Beautiful order summaries
✅ **WhatsApp Integration** - Send orders directly to WhatsApp group
✅ **Copy to Clipboard** - Export orders for email/SMS
✅ **Mobile Responsive** - Works on phones, tablets, and computers
✅ **Zero Setup** - No server required, no dependencies
✅ **Offline Ready** - Works without internet connection

## 📱 Supported Products

- **BULKPACK Products** (P001-P073): Rice, oils, spices, grains, dairy
- **SPICES Products** (S001-S049): All types of spices and powders

## 📋 How to Use

### Step 1: Enter Sales Agent Name
- Type your name in the "Sales Agent Name" field
- This will appear in all orders

### Step 2: Select Store
- Type or select store name from dropdown
- If not in list, just type a new store name

### Step 3: Add Products
- Search by product name (e.g., "Rice", "Chilli")
- Or search by product code (e.g., "P001", "S031")
- Click to add to order
- Repeat for multiple products

### Step 4: Adjust Quantities
- Change quantity in the order summary
- Remove items with the X button

### Step 5: Send to WhatsApp
- Click "🔗 Send to WhatsApp Group"
- Order opens in WhatsApp
- Paste in your team group chat

**OR**

- Click "📋 Copy to Clipboard"
- Paste anywhere (email, message, etc.)

## 📦 Installation & Deployment

### GitHub Pages (Free Hosting)

1. **Create GitHub Account** (if you don't have one)
   - Go to https://github.com/signup
   - Sign up and verify email

2. **Create New Repository**
   - Click "+" → "New repository"
   - Name: `daily-food-order-app`
   - Description: "Order management system for Daily Food Products"
   - Make it PUBLIC
   - Click "Create repository"

3. **Upload Files**
   - Click "Add file" → "Upload files"
   - Upload `index.html` and `README.md`
   - Click "Commit changes"

4. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Under "Source", select "main" branch
   - Click Save
   - Wait 1 minute for deployment

5. **Your App is Live!**
   - Visit: `https://your-username.github.io/daily-food-order-app/`
   - Share this link with your team

### Local Setup (For Developers)

```bash
# Clone repository
git clone https://github.com/your-username/daily-food-order-app.git

# Navigate to directory
cd daily-food-order-app

# Open in browser
open index.html
# or
start index.html
# or just double-click index.html
```
