📱 HOW TO USE THE APP
================================================================================

1. ENTER SALES AGENT NAME
   └─ Type your name in the first field

2. SELECT STORE
   └─ Choose from dropdown or type new store name

3. SEARCH PRODUCTS
   └─ Type product code (P001, S031)
   └─ Or product name (Rice, Chilli)
   └─ Click to add

4. ADJUST QUANTITIES
   └─ Change numbers in order summary
   └─ Prices update automatically

5. SEND TO WHATSAPP
   └─ Click "Send to WhatsApp Group"
   └─ Order opens in WhatsApp
   └─ Paste in group chat

TIME PER ORDER: 2-3 minutes ⚡

================================================================================
🆘 TROUBLESHOOTING QUICK FIXES
================================================================================

PROBLEM: "Link doesn't work"
SOLUTION: Wait 2 minutes and refresh (Ctrl+Shift+R)

PROBLEM: "Can't find product"
SOLUTION: Try product code (P001) instead of name

PROBLEM: "WhatsApp not opening"
SOLUTION: Use "Copy to Clipboard" button instead

PROBLEM: "App loads slowly"
SOLUTION: Check internet, hard refresh, try different browser

PROBLEM: "GitHub Pages won't enable"
SOLUTION: Make sure repository is PUBLIC, not private
