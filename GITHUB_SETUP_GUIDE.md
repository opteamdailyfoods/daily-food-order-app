## Step-by-Step Setup

### STEP 1: Create GitHub Account (If you don't have one)

**Time: 2 minutes**

1. Go to https://github.com/signup
2. Fill in:
   - Username: (e.g., `daily-food-products`)
   - Email: (your company email)
   - Password: (create strong password)
3. Click "Create account"
4. Verify your email
5. Done! ✅

---

### STEP 2: Create New Repository

**Time: 2 minutes**

1. Log in to GitHub (https://github.com/login)
2. Click the **"+"** icon (top right) → **"New repository"**
3. Fill in details:

```
Repository name: daily-food-order-app
Description: Order management system for Daily Food Products SDN BHD
Public: ✓ (Make it PUBLIC)
Initialize with README: ✓
```

4. Click **"Create repository"** button
5. Done! ✅

---

### STEP 3: Upload the App Files

**Time: 2 minutes**

1. In your repository, click **"Add file"** → **"Upload files"**

2. Drag & drop or select these files:
   - `index.html` (the main app file)
   - `README.md` (already provided)

3. In the "Commit changes" section, type:
   - Message: `Initial commit: Add Daily Food Order app`

4. Click **"Commit changes"** button

5. Done! ✅

---

### STEP 4: Enable GitHub Pages

**Time: 1 minute**

1. Go to your repository **Settings** tab
2. Click **"Pages"** in the left sidebar
3. Under **"Source"**, select:
   - Branch: **`main`** (or `master`)
   - Folder: **`/ (root)`**
4. Click **"Save"** button
5. Wait 30 seconds to 1 minute
6. Done! ✅

---

### STEP 5: Get Your Live Link

**Time: 1 minute**

1. Go back to **Settings** → **Pages**
2. Look for: **"Your site is published at:"**
3. You'll see your live URL:
   ```
   https://your-username.github.io/daily-food-order-app/
   ```

**That's your app link!** 🎉

## 🆘 Troubleshooting

### Q: "Page not found" after deployment
**A:** Wait 2-3 minutes after enabling GitHub Pages. Then refresh browser (Ctrl+Shift+R or Cmd+Shift+R).

### Q: Changes not appearing
**A:** 
1. Hard refresh browser (Ctrl+Shift+R)
2. Clear browser cache
3. Wait 2 minutes
4. Try different browser

### Q: App not loading on mobile
**A:**
1. Make sure link is PUBLIC (check GitHub Settings)
2. Try different mobile browser
3. Check internet connection

### Q: Need to disable the site temporarily
**A:**
1. Go to Settings → Pages
2. Under "Source", select "None"
3. Click "Save"
4. To re-enable: Select "main" branch again
