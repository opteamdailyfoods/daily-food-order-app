# 📱 Quick Start Guide - Daily Food Products Order App

**Using the app takes less than 2 minutes!**

---

## 🎯 The 5-Minute Tutorial

### Step 1: Open the App (10 seconds)
Click the link your manager sent you:
```
https://your-username.github.io/daily-food-order-app/
```

### Step 2: Enter Your Name (15 seconds)
```
👤 Sales Agent Name
├─ Type: Your name
└─ Example: "Ahmad" or "Priya"
```

### Step 3: Select Store (30 seconds)
```
🏪 Store Name
├─ Option A: Click dropdown and select
├─ Option B: Type store name
└─ Example: "ABC Store" or "XYZ Mart"
```

### Step 4: Add Products (1 minute)
```
🔍 Search Products
├─ Search by name: "Rice" or "Chilli"
├─ Or by code: "P001" or "S031"
├─ Click product from dropdown
└─ Repeat for multiple products
```

### Step 5: Review & Send (30 seconds)
```
✅ Check order summary
├─ Adjust quantities if needed
├─ Click "Send to WhatsApp Group"
└─ Order opens in WhatsApp
```

### Step 6: Paste in Group Chat (10 seconds)
```
💬 WhatsApp Group
├─ Copy the formatted message
├─ Paste in group chat
└─ Send! 📤
```

**Total Time: ~2 minutes!**

## ⚡ Pro Tips

### Tip 1: Search Faster
- Type product code (P001, S031) instead of full name
- Saves typing time!

### Tip 2: Add Multiple Items
- Don't close dropdown between products
- Just keep searching & clicking
- Much faster!

### Tip 3: Adjust Quantities
- Can change quantity anytime before sending
- Click the number field and edit
- Price updates automatically ✓

### Tip 4: Remove Products
- Click the X button to remove
- Or set quantity to 0
- Easy to fix mistakes!

### Tip 5: Copy & Send Later
- "Copy to Clipboard" button if WhatsApp not handy
- Paste in email, SMS, or message later
- No need to send immediately

## 🐛 Common Issues & Fixes

### "App not loading"
```
Fix:
1. Refresh page (F5 or Ctrl+R)
2. Try different browser
3. Check internet connection
```

### "Can't find product"
```
Fix:
1. Check spelling carefully
2. Try product code instead of name
3. Ask manager for product code list
```

### "WhatsApp won't open"
```
Fix:
1. Make sure WhatsApp is installed
2. Try "Copy to Clipboard" instead
3. Manually paste in chat
```

### "Quantity not updating"
```
Fix:
1. Click outside the field after editing
2. Refresh page
3. Try different browser
```
